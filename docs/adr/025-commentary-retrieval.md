# ADR-025: Retrieve BAG commentary passages and generate cited explanations in `tools/`, outside the tariff services

*Status: Accepted (by Erhan's explicit decision on 2026-11-14; proposed the same day) · Date: 2026-11-14 · Decider: Erhan (+ AI-assisted analysis)*

## Context
The Change Analyst needs passages from the BAG commentaries, cited by document, edition and page, beside the deterministic edition comparison ([ADR-023](023-al-edition-comparison.md), [ADR-024](024-al-workbook-text.md)), and an explanation of a change that cites them. The manifest pins each edition's commentary PDF by SHA-256, but nothing reads it ([ADR-021](021-al-manifest-import.md)). [ADR-005](005-single-ai-seam.md) allows exactly one live-AI seam, `ai_map`, and `test_value_path_boundary.py` lets only `mappers/tariff_mapper.py` import an LLM client, so a retrieval and answer path inside a service would have to widen that guard.

## Decision
Retrieval and cloud-generated explanations both live in `tools/commentary_rag/`, outside every service, with no access to the tariff database and no write to it. Each edition's commentary PDF is read through the manifest loader, from its hash-verified bytes, into page-bounded passages carrying edition, document hash, page and section, and ranked with BM25, multilingual-e5 and their reciprocal rank fusion over an explicit edition selection. For an explanation, the top 5 passages of the hybrid ranking under the edition filter go, with their provenance, to the Anthropic Messages API directly (`claude-opus-5-5`, effort `max`, adaptive thinking), one request per question, without tools, web search, MCP servers or a fallback model. The answer is a structured status, claims with passage citations and stated missing evidence, validated locally for schema and citation membership. Spending is bounded before sending: every request is counted with the provider's token counter, its ceiling cost is reserved in an append-only ledger, and requests stop at the attempt cap or the budget. The generated text never computes, updates or replaces an authoritative tariff record or billing result; it may quote the tariff numbers that the public BAG passages state. This is a second, read-only AI seam on public documents, outside the services (global region allowed by [ADR-012](012-data-residency-llm-region.md)); `ai_map` stays the only AI seam inside them.

## Alternatives weighed
- **Inside `services/ingestion`**: the generation step would need the boundary test's LLM allowlist widened, weakening the guard that keeps LLM clients off the value path.
- **A pgvector table for passages**: a schema change and a migration for fewer than 50 passages that exact in-memory cosine ranks deterministically.
- **A local generative model**: not chosen; the owner prefers a cloud API (2026-11-14).
- **Dense retrieval only**: BM25 keeps position codes such as `1368.00` as single terms and gives the lexical baseline the comparison needs.
- **A provider-neutral client layer**: not built; one provider and one model are decided, and the installed `anthropic` client (already locked in the ingestion service's `ai` extra) is reused without any lockfile change.

## Consequences
- (+) Retrieval runs offline on the cached model, reproducibly on one machine (two baseline runs and a pre-generation rerun of the corrected run gave identical rankings and scores), from verified sources, with the services, schema, frozen records and boundary tests unchanged ([evidence](../evidence/2026-11-14-commentary-retrieval.md)).
- (+) Every passage keeps its provenance: edition, document SHA-256, BAG URL, PDF page with the printed page label checked, and section; every generated claim cites passage IDs that are checked against its own request's context (first run: eight schema-valid answers, all 54 citations in context, $1.93 calculated; [generation evidence](../evidence/2026-11-15-commentary-generation.md)).
- (-) The tool reuses private helpers of the manifest module and the e5 embedder (`_load`, `_verify`, `_e5_input`, the model handle); a change there breaks the tool, not the services. Sections are inferred from numbered headings, and footnotes join the last section on their page.
- (-) Citation-ID checks are not semantic validation: whether a passage supports a claim needs human review. Update 2026-11-15: Erhan Ünlü's review of the first run, confirmed on 15 November 2026, judged the eight AI-drafted dev cases and their reference expectations appropriate and all 48 structured claims supported by what they cite (27 fully relevant), with 14 of 19 required rubric claims covered (D1's five missing after its retrieval miss). It is one non-blinded reviewer's judgement on eight dev cases with no held-out test, not an accuracy figure ([generation evidence, human review](../evidence/2026-11-15-commentary-generation.md#human-review-completed-2026-11-15); `tools/commentary_rag/results/2026-11-15-human-review-summary.json`).
